# Agent-guided learning workspace

For installation or setup from a repository link, follow `INSTALL.md`.

For learning, continuation or review, use `skills/learning-guide/SKILL.md`.
The active conversation supplies instructional judgment. Executable tools provide
records, source acquisition, activity publication, capture, projections and launch.
No extra model runner is needed. All learner state belongs to its course folder.

For development, read README.md and docs/architecture.md. Preserve the earlier
experiments. Validate changes with `python3 -m unittest discover -s tests -v`,
`node --check web/app.js`, `node --check web/activity.js` and `node --check web/bridge.js`.
Use temporary directories and explicitly fictional courses for QA. Never put demo
answers, fabricated observations or author assessments in `courses/`.

Published activities and journal events are immutable. Use tools to publish new
versions, record superseding assessments and rebuild disposable state projections.
Do not edit receipts to bless modified source originals. Keep dependencies and
credentials in disposable runtime environments outside course evidence.
